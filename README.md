# Hotel Reservations API (NestJS simulation)

REST API built with NestJS, TypeORM and PostgreSQL for the fictional company
Arenosa Hoteles S.A.S.

> Work in progress: the full documentation (installation, test users,
> HTTP status code justification and test evidence) will be added at the end
> of the project.

## Database

PostgreSQL runs inside a Docker container.

```bash
cp .env.example .env
docker compose up -d
```
